# Security

Report vulnerabilities privately to Clouvel (`clouvelai`) with a
[GitHub security advisory](https://github.com/clouvelai/ardoise/security/advisories/new)
on this repo. Do not file a public issue for a vuln.

Do not commit secrets, API keys, or `.env` files. `.env` and `.env.*` are
gitignored (`.env.example` is the exception).
